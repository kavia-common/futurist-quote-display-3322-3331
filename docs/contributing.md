# Contributing Guidelines

Thank you for your interest in contributing to the Jarvis-Inspired Quote Display App!

## How to Contribute

We welcome contributions from all developers. Improvements can include new features, UI refinements, animation enhancements, bugfixes, or documentation updates.

### Getting Started

1. **Fork the repository** and clone it to your local machine.
2. **Install dependencies** by running `npm install` in `jarvis_quote_frontend/`.
3. **Create a new branch** for your feature, fix, or update.

### Recommended Workflow

- Keep your changes focused and clearly scoped.
- Update or add documentation for any major changes or new features.
- Write or adjust tests if applicable.
- Check your code with `npm run lint` (if configured) before committing.

### Pull Request Process

1. **Open a pull request** to the main branch describing your changes and why they are needed.
2. Maintain clear commit messages.
3. Link relevant issues if applicable.

### Code Style

- Use consistent formatting and follow existing patterns in the codebase.
- Prefer functional React components and hooks.
- Use color variables and conventions per the [Style Guide](style-guide.md).
- Keep the UI/UX consistent with the Jarvis/hud-inspired aesthetic.

### Reporting Issues / Feature Requests

- Search existing issues before creating a new one.
- Provide as much detail as possible (screenshots are welcome).
